3. Not distributed to browsers
------------------------------

The build and test tooling (Vite, TypeScript, esbuild, Rollup, Babel, PostCSS and
their dependencies) runs on the build machine only. None of it is served, so its
licences — MIT, ISC, BSD-3-Clause, CC-BY-4.0 and Apache-2.0 — are recorded in
THIRD-PARTY-NOTICES.md for transparency rather than by obligation.


4. No NOTICE file
-----------------

Apache-2.0 requires a NOTICE file only when redistributing code that already
carries one. No component listed here ships one, so none is reproduced. If a
future dependency does, it is added to THIRD-PARTY-NOTICES.md at the same time as
the dependency.
